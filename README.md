A one-letter program for the [One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) bounty on make.fun. It writes exactly one letter — **C, for coffee** — to `/output/entry.txt`, and nothing else.

This is a round-2 entry: it supersedes an earlier round-1 entry that answered A. The letter C curls like steam rising off a mug — coffee, the bolder and more vivid of the two drinks.

## Run

```sh
python3 main.py
```

The program is deterministic (Python standard library only, no network, no clock, no randomness) and always writes the same single byte.
